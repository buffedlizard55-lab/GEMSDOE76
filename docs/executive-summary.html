Before a file can be released

  1. Establish inputs and lane. Resolve the parallel-run method assignment, place hash-pinned shared feature caches, authenticate sample/catalogue and data eligibility, and refresh the complete scoped raster registry.
  2. Validate science. Run feature-alone leakage canaries, buffered whole-segment spatial hide-and-recover, and a frozen current-best comparator. Every catalogue feature must use visible faults only. Pool DTI components and report version, withheld positives and 95% confidence intervals.
  3. Prove distinctness in the accessible scope. Check the surface before placement and the final dots. Stop if rank correlation exceeds 0.90 or forward dot overlap within 3 pixels exceeds 70% against any prior. Missing priors are not a clearance.
  4. Package once, without silent repairs. Use the shared writer for single-band float32 GeoTIFF and, optionally, a ZIP containing only that TIFF. Predictions must already be finite and in [0,1]. Zero the exterior explicitly; mask visible catalogue pixels exactly. Verify CRS, shape and transform against the authenticated format.
  5. Separate selection from generation. Require a documented holdout improvement against the current best and selector approval. Check current contest rules and the remaining weekly cap on the organizer’s submission page. No slot is authorized here.

Only after a genuinely approved file is published

  1. Download the file explicitly marked as the approved prediction, not a reference or diagnostic. Compare its SHA256 against its adjacent receipt.
  2. Sign in to the official competition, review eligibility/rules, then open its New submission form. Follow the current organizer instructions if they differ from this retained brief.
  3. Choose the approved single-band .tif, or its one-TIFF .zip, as “File to submit”. Do not upload a document.
  4. Copy the artifact’s unique submission name and its note of at most 140 characters from its receipt. There is no candidate name or note intended for upload in this negative run.
  5. Submit only after the selector approves the slot. Save the submission-page receipt and organizer result. Only then label a score ORGANIZER-CONFIRMED.

Prevent the reported range error

The offending file was not available, so its exact cause is unknown. We reject NaN, infinity, negative values, values above one and incompatible nodata rather than silently clipping them. We validate the serialized file—not just the array in memory.
